# Contributing

Gracias por contribuir. Mantenga los cambios pequeños, documentados y libres
de datos de personas, organizaciones o infraestructura reales.

1. Cree una rama desde `main`.
2. Ejecute las validaciones de la aplicación modificada.
3. Actualice la documentación o un ADR cuando cambie una decisión técnica.
4. Envíe un pull request con una descripción y evidencia de pruebas.

No incluya archivos `.env`, credenciales, direcciones internas, imágenes de
personas ni dumps de base de datos.
